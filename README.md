# XHPure Music

基于 Vue 3、Vite 和 Electron 的本地音乐播放器。

## 安装依赖

```sh
pnpm install
```

## Electron 开发

```sh
pnpm dev
```

## Web 开发

```sh
pnpm dev:web
```

## 构建 Web 版本

```sh
pnpm build:web
```

## 构建 Windows 桌面包

```sh
pnpm build
```

## 类型检查

```sh
pnpm type-check
```

## Lint

```sh
pnpm lint
```
